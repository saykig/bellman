## Keeping this useful

Append a dated entry after each meaningful research milestone, failed approach,
correction, or pause. Give it a stable ID; record the question, premises, finding,
evidence level, original artifact links, commit identity, unresolved issues and
which earlier entries it changes. A negative result is progress too.

Do not erase superseded findings or overwrite old result receipts. Add a correction
entry naming the affected claim and explaining what survives. Preserve distinctions
between a written proof, finite computation, Lean check, conjecture, proposal and
external validation. A prepared runner is not an executed experiment.

These ledgers summarize evidence; original mathematical records remain authoritative.
No new research is authorized merely by listing a next question here. Historical
“uncommitted” or temporary “do not commit” statements describe their original runs;
the later user instruction authorizes this preservation and regular commits.
