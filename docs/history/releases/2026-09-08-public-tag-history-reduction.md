# Specified public-tag history reduction

8 September 2026. Research state transition on draft PR #22; not a published version
or external mathematical acceptance. Exact source identity and observations are in
`verification/history_reduction/results.json`.

An additive proof now shows when an initial public tag can be erased while preserving
all continuation incentives and a common off-path consistency sequence. Each positive
public branch must be a copy of the same continuation game, supplied strategy and
assessment. The reference reduces 127 nodes to 63, with 160 -> 80 model/information
queries, and checks the source and target independently using the established receivers.

Two exact counterexamples block broader shortcuts: a payoff-irrelevant public tag can
coordinate actions, and matching root utilities/incentives do not preserve off-path
likelihoods. General history compression remains open. The live reproduction link now
points to the new aggregate acceptance guide. Earlier frozen sources and release
identities remain unchanged; no causal, Writ or Decision Lab transfer is made.
