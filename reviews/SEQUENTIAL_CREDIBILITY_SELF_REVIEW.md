# Sequential credibility: author self-review

8 September 2026. This is an author review and targeted falsification record, not independent peer review.

## What the package actually establishes

The finite checker computes the largest permitted conditional continuation gain for one supplied behavioral profile across a shared finite tree family and explicitly assessed information sets. The exact fixture passes with zero gain in 80 model/information-set queries. The claim is uniform assessment-relative sequential rationality. On-path Bayes checks are part of receiving; off-path limiting consistency is not.

## Mathematical audit

1. Quantifiers: the same profile is supplied across models; deviations can differ when witnessing failure. Certifying every model/deviation separately establishes the universal criterion. It does not prescribe model-indexed strategies to actors.
2. Full continuations: enumeration covers all deviator information sets in the union of subtrees below the starting information set. It is not a one-step root check. The Enter/Take example catches that shortcut.
3. Information: assignments are keyed by information set, not by node. Recall validation compares own prior information/action sequences. The hidden-quality posterior test conditions a mixed disclosure profile and rejects a normalized but incorrect posterior.
4. Randomization: per-path no-repeat information sets permit finite expansion into pure plans. The mixed-disclosure fixture exercises a genuinely non-pure proposed profile. This is expected utility within each model, not a Kuhn theorem for ambiguity-sensitive preferences.
5. Off-path behavior: zero-reach information sets are retained with supplied distributions. The costly-threat control fails there despite no root deviation. Stronger consistency cannot be inferred from these checks.
6. Representation: the 2-delta proof is a triangle inequality plus deviation coverage, not a generic abstraction algorithm. The positive executable cases are bijective relabelling and bounded terminal utility changes; deleting evidence is not accepted as a free compression.
7. Continuous theorem: multiply the conditional bound by a positive reach denominator; then check multi-affine unnormalized inequalities. The ratio itself need not be multi-affine. Endpoint arithmetic does not validate the hypotheses, and generic continuous subject receiving is unsupported.
8. Mechanisms: fee and bond changes are freshly evaluated. The participation failure with an otherwise deterring bond prevents equating compliance incentives with voluntary entry.

## Implementation audit

The producer recursively evaluates nodes. The receiver enumerates its own plan products and iteratively accumulates terminal paths. Neither trusts a numerical solver. Shared validation, Fraction arithmetic and Python execution remain in the trusted base. An isolated receiving process contains only receiver.py and subject.py, with no producer or fixture code. The receiving query supplies epsilon independently; a changed certificate tolerance cannot silently weaken the requested query.

The format is a bounded research interface, not a hardened parser for an exposed service. Resource limits are explicit but do not constitute a performance or denial-of-service guarantee. Frozen base files are checked byte-for-byte; old suites are not rerun and no historical replay claim is made. Normal and optimized execution are compared; assert is not used as input validation.

## Fixes made before retained evidence

- Added independently supplied receiving tolerance after identifying that a certificate-only epsilon could change the query.
- Added a nontrivial on-path hidden-type posterior control; the initial singleton posterior control alone only tested normalization.
- Explicitly reject the unsupported no-player subject rather than reaching an empty maximum.

## Disposition

Suitable for review as a first bounded integrated research component. Not ready to claim full sequential equilibrium, empirical credibility, general mechanism synthesis, arbitrary history compression, or an automatic causal-kernel-to-strategy bridge. No Lean trigger or solver-search requirement has been reached by this bounded result. The continuous and off-path consistency boundaries are substantive candidates for the next mathematical gate.
